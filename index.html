Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau's method is a way to linearly interpolate Bezier curves. Bezier curves will have control points, points on the curve that define how the line curves. De Casteljau works by connecting a straight line between each neightbouring control point. It then selects a new point on this straight line, defined by a parameter weight. If the parameter were 0.5, it would make a new point halfway between each original control point. It then recursively repeats this process until there is only one point left. This final point makes a singular point of the Bezier curve. By moving the weighted parameter from 0 to 1, we can define the entire Bezier curve.

The algorithm is implemented with one level in this part. Inside a loop, vector math performs each recursive interpolation step. The loop returns the n - 1 points, which is then passed to an outer method which continues the recursive deepening.

Part 2: Bezier surfaces with separable 1D de Casteljau

To implement this same algorithm but for full surfaces, we essentially wrap the previous steps within another loop. In more detail, we now use two parameters u and v, similar to x and y on a 2D plane. The interpolation first works on a row of points, just like the previous part. It does this for every row, condensing it into a singular column. It finally performs one last interpolation on the column, which returns a single point. This point is combined with the other points made from different u and v values to create the surface.


Section II: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-weighted vertex normals

First, lets go over the concept of half edges. Typically, if we want to look for all the shapes connected at a vertex, a coordinate system would require us to iterate through all of the shapes to identify which one connects at a vertex. Half edges represent the shared edges between shapes as directed graphs, allowing us to traverse between edges to find shapes connected to the vertex.

This is important because to make area-weighted vertex normals, we need to find the shapes connected to a vertex. Using the half edges to traverse between faces, we can extract the positions of all the vertices of each face and make vectors connecting them. Taking the cross product of these vectors makes a new vector, normal to the face. Then doing a weighted average of these face vectors allows us to assign a value to the vertex, its "vertex normal vector".

Why is this important? We have two different shading methods. The first is called flat shading, which just looks at the face normal vector and assigns a light value to it. This creates distinct geometrical lighting, which might be nice for sharp edges but bad for curved, continuous surfaces. The second is called Phong shading, which makes use of the vertex normals we previously mentioned. It looks at the vertex normals around a triangle, and does a barycentric interpolation with those three vectors, creating a smooth, gradient shading effect.

Part 4: Edge flip

Edge flipping is a technique that given a quadrilateral formed of two triangles, we simply flip the internal edge to the other two vertices. The purpose of this is that skinny, long triangles are often much harder to smoothly render, we like even, equal shapes. Therefore, there are times where it can be useful to change the internal edge of a quadrilateral, making it such that instead of being made of two skinny triangles, it is now made of two triangles that are much closer to equilateral.

This is implemented by first taking a complete snapshot of the half edges and vertices. Basically, lots of copies are made. Then, the reassignment begins, using a helper method setNeighbours to reassign the inner edgtes, and manually reassigning the outer edges and vertices.

Part 5: Edge split

Edge splitting works very similarly to edge flipping, but instead of just flipping the edge to the other two vertices, we split the middle edge by connecting its center to the other two vertices with new edges. We are essentially adding new edges to a previous shape, or increasing the number of triangles. This is useful for upscaling, increasing the amount of geometry allows for more detailed textures.

The way that this is implemented is similar to edge flipping, we first take a snapshot of our quadrilateral. Memory is then instantiated for the new edges/vertices that we want to create. Then the half edges are remade/added accordingly with these new faces and edges. Finally, any of the connections with the outside of these faces are manually rewired to fit the new faces that we added.


Effect of edge splitting can be much more subtle than edge flipping.

Part 6: Loop subdivision for mesh upsampling

Loop subdivision is an upsampling method that combines flipping and splitting from the previous parts. Whole increasing the number of faces through splitting does create better texturing, ultimately the position of the vertexes don't really change, the new faces could still recombine into one flat face. Loop subdivision enhances this aspect by slightly pulling on the new center vertex and the surrounding vertices, creating a roundness to the new faces. It also attaches some flipping, ultimately causing the original triangle to split into 4 new triangles, very similar to the shape of the Triforce from The Legend of Zelda.

The way that this is done is through a three step process. First, the target new vertex positions are calculated before any edge splitting is done. These are also saved in a new location to not affect the edge splitting. Then comes the actual edge splitting, which is also followed by flipping any edge that connects an old vertex to a new one. The algorithm then does a final pass, overwriting the vertices' positions with their new positions and resetting the scheme for future loop subdivisions.
